The problem

The corruption nobody catches.

A GPU silently produces wrong gradients. The training job continues. The hardware reports healthy. The dashboards show green.

Days later, an engineer notices the loss curve looks off. They roll back to the last good checkpoint, restart the run, and try to figure out which GPU caused it. The compute is gone. The deadline slips.

NVIDIA DCGM doesn't catch it. Datadog doesn't catch it. Weights & Biases doesn't catch it. Hyperscalers solve this internally — and don't share their tools.

The approach

Four layers, watching every step.

A single technique can't catch every kind of corruption. We run four detection layers in parallel, each tuned to a different failure mode.

L1 / coarse anomaly

Catches the obvious

NaN propagation, infinity values, gradient norm explosions. Fires in the same step the corruption appears.

→ bit-flip exponent · NaN injection
L2 / parameter checksums

Catches the subtle

Tracks statistical fingerprints of every weight tensor. Detects single-bit corruption that other layers miss entirely.

→ mantissa flips · partial corruption
L3 / statistical drift

Catches the gradual

Monitors model trajectory over time windows. Flags slow divergence that single-step checks would miss.

→ accumulating errors · soft faults
L4 / selective replay

Confirms the alert

When suspicious behavior is detected, we re-run the computation deterministically and compare. Definitive verification.

→ eliminates false alarms
